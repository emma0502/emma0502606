## What the paper asks

The paper develops a model in which the composition of public debt across
**domestic banks, domestic non-banks, and foreign investors** is determined by
endogenous borrowing limits. The government faces default constraints on
non-bank creditors and convex costs of financial repression on bank-held
debt. These constraints generate threshold effects: when total debt
exceeds a critical level, the government exhausts non-bank borrowing
capacity and allocates marginal debt to banks.

The paper structurally estimates the model using panel data on debt
composition across countries and over time. The estimation identifies
distinct borrowing limits across creditor types and provides a tractable
framework for interpreting variation in who holds government debt.

## Quick start

### Compile the paper PDF

```bash
./reproduce.sh --docs
```

Output: `emma0502606.pdf`. Requires TeX Live 2023+ with the packages
listed in `reproduce/required_latex_packages.txt`.

### Full reproduction

```bash
./reproduce.sh --all        # equivalent to ./reproduce.sh
```

This runs the **Python** empirical pipeline under
`Code/empirical_debt_composition/python/` and then compiles the paper.
If Python is not available the script falls back to Stata when present,
otherwise it skips the empirics with a clear message and just compiles
the paper from the committed sources (regression numbers are
transcribed into `Subfiles/Empirical.tex`; auto-emit is a named
follow-up).

### Empirical pipeline (Python — no Stata required)

```bash
./reproduce.sh --python
```

Invokes `python -m Code.empirical_debt_composition.python.run_all`.
This is a pure-conda pipeline that reproduces every regression
reported in Sections 6.3 -- 6.6. It writes per-stage logs and a
`validation_summary.txt` to
`Code/empirical_debt_composition/results/python/`, and was validated
cell-by-cell against the canonical Stata logs:

| Quantity | Agreement with Stata |
|---|---|
| Coefficients (every spec, all of §6.3 -- §6.6) | identical to >= 6 decimals |
| Cluster-robust SEs (one-way, country) | within 0.1% relative |
| Cluster-robust SEs (two-way, country & year) | within ~1--8% relative (Cameron-Gelbach-Miller small-sample correction differs slightly from `ivreg2`) |
| Sample sizes (N) | identical (547, 718, 732, 753, 780, 463, 701, 747, ...) |
| Statistical conclusions (significance at 1%, 5%, 10%) | identical |

### Smoke test

```bash
./reproduce.sh --check
```

Runs an abbreviated version of the Python pipeline and asserts that
the headline numbers in §6.3, §6.4, §6.5, §6.6 still match the
committed Stata logs to within tolerance. Exits non-zero on
mismatch, so this can be wired into CI.

### Empirical pipeline (Stata — canonical reference)

```bash
./reproduce.sh --empirical
```

Invokes `stata -b do Code/empirical_debt_composition/run_all.do`.
Requires Stata 17+ on PATH as `stata-mp` / `stata-se` / `stata`. Use
`--python` instead if you don't have a Stata licence.

### Reproduction times

Wall-clock times measured on a WSL2 Ubuntu 24.04 box on a 12-core
x86\_64 host with 7.7 GB RAM, TeX Live 2023, Python 3.9. All numbers
cover the `./reproduce.sh` step only, not container build.

| Command | Wall time | What it actually does on this machine |
|---|---|---|
| `./reproduce.sh --check`    | ~5 s    | Smoke test: re-runs three regressions, asserts headline numbers match Stata. |
| `./reproduce.sh --python`   | ~75 s   | Full Python pipeline: 4 Hansen threshold grid searches + Stage 1 + Stage 2 + §6.6 specs. Writes per-stage logs and a validation summary. |
| `./reproduce.sh --docs`     | ~6 s (warm `.bbl`) | Two `pdflatex` passes + one `bibtex` pass on `emma0502606.tex` via `latexmk`. |
| `./reproduce.sh --all`      | ~80 s   | Python pipeline + `--docs`. |
| `./reproduce.sh --empirical` (Stata 17+ on PATH) | ~60 s | Runs the three canonical `.do` files in `Code/empirical_debt_composition/`. |

`./reproduce.sh --all` is well under STANDARD.md's 5-minute threshold for
the optional `reproduce_min.sh`, so this REMARK does not ship one.

## Known limitations and follow-ups

These items were surfaced by a Claude Opus 4.7 review of this repo
against the [REMARK STANDARD](https://github.com/econ-ark/REMARK/blob/main/STANDARD.md).
They are tracked here so any gap remaining after this commit is visible
to a reviewer.

### Limitations (intentional, documented)

1. **Cluster-robust SE small-sample correction.** The Python
   two-way clustering implementation in
   `Code/empirical_debt_composition/python/_common.py` differs from
   Stata's `ivreg2 ..., cluster(country_id year) small` by ~1--8% on
   reported standard errors. Coefficients are identical to >= 6
   decimals, sample sizes match exactly, and statistical conclusions
   (significance at 1% / 5% / 10%) match Stata in every spec
   reported in the paper. The discrepancy is the
   Cameron-Gelbach-Miller small-sample-correction degrees of freedom
   convention (which K to use in the (N-1)/(N-K) factor when entity
   FE are absorbed). The committed Stata logs remain the canonical
   reference for SEs.

### Follow-ups

1. **Auto-emit regression tables** from the Python pipeline so that
   `Subfiles/Empirical.tex` `\input{...}`s them instead of carrying
   transcribed numbers inline.
2. **Auto-emit figures** from the pipeline instead of relying on the
   currently committed PDFs/PNGs under `Figures/`.
3. **Scripted data build.** Replace the offline Excel/Stata merge that
   produced `Data/gfdd_with_de_facto1.dta` with a `build_panel.py`
   that starts from the raw GFDD, Arslanalp-Tsuda, EWN, Chinn-Ito,
   Quinn, and IMF BOI sources. See `Data/README.md` for the source
   inventory.
4. **Tighten the SE small-sample correction** in
   `_common.py` to match `ivreg2 ..., small` exactly (note above).
5. **Audit the `Dockerfile`** for any remaining HAFiscal-specific
   paths.
